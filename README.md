# 🐍 مار حرفه‌ای — Snake Pro

یک بازی مار کامل و حرفه‌ای، فقط در **یک فایل HTML مستقل** (`snake.html`).
بدون کتابخانه، بدون سرور، بدون اینترنت — فایل را در هر مرورگری باز کنید و بازی کنید.

## اجرا
فایل `snake.html` را دانلود و دوبار کلیک کنید (یا در مرورگر بکشید و رها کنید). همه‌چیز آفلاین کار می‌کند.

## امکانات
- **۴ حالت بازی:** کلاسیک، بی‌دیوار (عبور از لبه‌ها)، هزارتو (موانع)، زمان‌دار (۹۰ ثانیه + پاداش زمان)
- **۴ درجه سختی** (آسان تا دیوانه) و **۳ اندازه زمین** (۱۵×۱۵، ۲۱×۲۱، ۲۷×۲۷)
- **۲۰ مرحله** با افزایش تدریجی سرعت، سیستم **کمبو تا ×۵** و ضریب امتیاز سختی/مرحله
- **جایزه‌ها:** میوه طلایی، سپر نجات، کندی زمان، امتیاز ×۲، شبح (عبور از دیوار و بدن)، کوتاه‌کن
- **رکوردهای کاربر:** جدول ۳۰۰ رکورد برتر با نام بازیکن، فیلتر بر اساس حالت/سختی، رکورد جدا برای هر ترکیب،
  آمار کامل (مجموع بازی‌ها، میوه‌ها، زمان، بلندترین مار، نوع باخت‌ها…) و **۲۱ دستاورد**
- **خروجی/ورود JSON** برای پشتیبان‌گیری و انتقال رکوردها + پاک کردن امن با تأیید
- **۵ پوسته رنگی:** نئون، رترو (LCD)، آتش، اقیانوس، روشن
- **گرافیک روان:** حرکت درون‌یابی‌شده، ذرات، لرزش صفحه، درخشش، اعداد شناور امتیاز، پشتیبانی HiDPI
- **صدا و موسیقی ساختگی** با Web Audio (بدون فایل صوتی)، کلید میان‌بر و تنظیم بلندی
- **موبایل‌پسند:** کنترل با کشیدن انگشت + دکمه‌های جهت، لرزش لمسی، چیدمان واکنش‌گرا و راست‌چین فارسی
- توقف خودکار هنگام ترک تب، شمارش معکوس شروع، ذخیره تنظیمات و رکوردها در `localStorage`

## کنترل‌ها
| کلید | کار |
|---|---|
| `↑ ↓ ← →` یا `W A S D` | حرکت |
| `Space` | شروع / توقف / ادامه |
| `Esc` یا `P` | توقف |
| `R` | بازی مجدد |
| `M` | قطع/وصل صدا |

## یادداشت فنی
منطق بازی با گام زمانی ثابت (fixed timestep) و رندر با `requestAnimationFrame` جدا شده است،
بنابراین سرعت بازی مستقل از نرخ فریم دستگاه است. یک API کوچک برای اشکال‌زدایی در `window.SnakePro` در دسترس است.
